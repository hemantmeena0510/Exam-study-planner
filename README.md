# 📅 Syllabus to Study Plan (AI)

Upload your syllabus PDF, set your exam date, and get a day-by-day roadmap: what to study, how to study it, and how many hours you need.

## Features
- **Upload PDFs/TXT:** syllabus, study material, notes, past papers (read in your browser, never uploaded to a server)
- **Full AI roadmap:** topic difficulty and importance, estimated hours, how to study each topic, must-know points, overall strategy
- **Smart schedule:** harder and more important topics get more time; last days reserved for revision
- **Hours advice:** warns when your daily hours are too low and tells you how much to study
- **Reschedule:** change study hours or fall behind, and the plan rebalances the days left
- **PDFs:** most-likely exam questions, revision notes, and your study plan
- **Works with Gemini, ChatGPT (OpenAI) and Claude:** add your own API key, or use **copy-paste mode** (no key): copy the prompt into ChatGPT / Gemini / Claude / NotebookLM and paste the reply back

## Run
Open `index.html` in a browser (needs internet for PDF libraries and AI).

## Deploy
Drag this folder to app.netlify.com/drop, or push to GitHub and import in Netlify (publish directory `.`).

## Privacy
Files are read locally. Text is sent only to the AI provider you choose. API keys are stored in your browser only, so don’t use this on shared computers.

## Notes
- Question predictions are estimates, not guarantees.
- Scanned (image-only) PDFs have no text; paste the text instead.
- Generated PDFs support English/Latin text only.
- Model names change; edit the model box if a default stops working.
